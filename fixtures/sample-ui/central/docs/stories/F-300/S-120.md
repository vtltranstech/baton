# S-120 The clerk decides from one screen whether an invoice can be sent
Feature: F-300

Labels: ui
Track: full

## Story
As a Billing Clerk, I want one screen with the invoice, its lines and its total so that I can decide to send it.

## Acceptance criteria
- AC1: Given an invoice, when the clerk opens it, then the customer, billing period, lines and total show (R2).
- AC2: Given an invoice with an unresolved line, when it is opened, then the total is hidden and the line flagged (R2).
- AC3: Given an invoice, when the clerk chooses Send, then it is sent.
