# CLI contract - `baton`

Entry: `python3 tools/baton/cli.py <cmd> ...` (installed as `baton` by `pyproject.toml`). Every subcommand: `--json` for machine output on stdout, human text otherwise; `--central <path>` defaults to the current directory. Exit codes: **0** ok - **1** verification/validation failure (reasons on stderr) - **2** missing input / refused.

| Subcommand | Reads | Writes | Owner |
| --- | --- | --- | --- |
| `extract-stack [--repo R]` | each repo's build files | `profile/stack-detected.md` (table per `artefacts.md` section 1) | W2 |
| `extract [--repo R]` | each repo's sources + config | `profile/dependencies.yaml`, seeded `profile/aggregates.yaml`, layout rows in stack-detected | W2 |
| `onboard [--interview]` | runs extract-stack + extract + c4 | prints open questions, with the `central` path and `repos` it read, as JSON; writes nothing else (the `/onboard` skill does the interview and the human-approved writes); exit 2 on the framework's own `fixtures/sample-*` unless `--allow-sample` | W2 |
| `profile --uri-var VAR --db DB [--collections a,b] --out docs/data-profile` | the datastore named by the env var only | `<collection>.md` + `.json` per `artefacts.md` section 5; never unmasked data; exit 2 if VAR is not the profile's `test.env.uri.var` | W3 |
| `wiki <repo> [--changed-since SHA] [--prose]` | repo sources, `dependencies.yaml`; the model only with `--prose` (one call per module, stops calling at a quota error) | `docs/wiki/<repo>/<module>.md` with frontmatter per `artefacts.md` section 6 | W4 |
| `verify <repo>` | wiki pages + extractors | `docs/wiki/<repo>/verify-report.json`; sets `verified: true` on passing pages; exit 1 on any failed page | W4 |
| `graph load [--store sqlite\|age]` | `profile/dependencies.yaml` of every repo | `.baton/graph.sqlite` (git-ignored) - idempotent upsert | W5 |
| `impact --repo R --diff FILE\|REF` | graph + the diff | `docs/qa/<F>/<S>-impact.json` when run by /build, else stdout | W5 |
| `c4 [--check]` | graph + `profile/project.md` + `profile/domain.md` externals | `docs/architecture/workspace.dsl`; `--check` diffs and exits 1 on drift | W5 |
| `c4 --story S [--date D]` | as `c4`, plus the recorded workspace and its stamps | `docs/architecture/workspace.dsl` with S's new and changed elements and relationships stamped (feature tag, `baton.story`, `baton.feature`, `baton.since`, `baton.changed-by`; versioning.md section 3), every earlier stamp kept; one row appended to `docs/architecture/CHANGELOG.md` and a `removed-by` row per removal; prints the counts; exit 2 when the story is missing. Plain `c4` keeps stamps and `--check` ignores them | W5 |
| `mutation --repo R --diff REF` | the repo, PIT config | `docs/qa/<F>/<S>-mutation.json` {score, changedClasses, killed, survived, notRun?} | W6 |
| `confidence <story-id>` | every artefact under docs/ for the story + `profile/confidence-weights.yaml` + `profile/risk-zones.yaml` | `docs/qa/<F>/<S>-confidence.json`; exit 0 always | W1 |
| `evidence <story-id>` | same + confidence.json | `docs/qa/<F>/<S>-evidence.md` | W1 |
| `state-check <story-file> <new-state>` | the story + its artefacts (Ready for PO, Ready and Designed: also gate 0, `docs/design/<F>/<S>-context.json` and `docs/context/understanding/status.json`, once `profile/branch-points.yaml` exists) | nothing; exit 0 / 2 with the missing prerequisite on stderr | W1 |
| `diagram story <S> [--check] [--spec F] [--diff REF [--repo R]] [--out D]` | the change spec `docs/design/<F>/<S>-change.yaml` (`artefacts.md` section 10), every repo's code map (`.baton/code/<repo>.json`, rebuilt from the AST when stale), the graph, profile/ | `docs/design/<F>/<S>-diagrams/` (section 11); with `--diff`, `docs/qa/<F>/<S>-as-built/` plus a conformance table; `--check` writes nothing; exit 1 when a spec name is not in the code, 2 when the story or spec is missing | diagram |
| `diagram architecture [--repo R] [--out D]` | the same | `docs/architecture/diagrams/` (section 11): context, containers and data, components per repo | diagram |
| `diagram context <Class \| Class#method \| resource-id>` | the same | nothing; a ~20-line card on stdout (`--json` for data): line ranges, signatures, calls, callers, data, tests, entry points; exit 1 on an unknown name with suggestions | diagram |
| `doclint [paths] [--fix] [--all-rules]` | Markdown under `docs/` (default) or the paths given | with `--fix`, the same files, non-ASCII characters replaced; exit 1 lists `file:line: rule: message` per the `doc-style` skill (ascii everywhere; bullet, paragraph, filler, note, heading on the documentation agent's files) | doc-style |
| `ir show [unit \| Class \| Class#method \| resource-id] [--all]` | the code map and the graph (as `diagram context`) | nothing; text on stdout (`--json` wraps it): no target = one line per unit; else operations with line ranges, behavioural calls, reads/writes/emits/http lifted through calls, callers and reaching entry points; overloads apart by signature; exit 1 on an unknown name with suggestions | workflow |
| `ir find <words> [--limit N]` | the same | nothing; the best-matching operations, classes and resources, one line each with file:lines and effects; exit 1 on no match | workflow |
| `ir slice <S> [--budget N] [--write]` | the same, plus `docs/design/<F>/<S>-change.yaml` when present, else the story's words | with `--write`, `.baton/context/<S>.md`: files and line ranges to open with reasons, the touched operations, shared data; within the token budget (default 3000) | workflow |
| `reads [--session ID \| --story S \| --all]` | `.baton/reads.jsonl` (the read_log hook) | nothing; per agent: calls, reads, re-reads, scans, ~tokens; files read by more than one agent; exit 1 when nothing is logged | workflow |
| `risk S` | the story; `docs/design/<F>/<S>-diagrams/diagrams.json` (touch points); `-diff-shape.json` when present; `profile/risk-zones.yaml`; `jira.labels.extra` in `profile/project.md` | `docs/qa/<F>/<S>-risk.json`: `tier` low / medium / high, `reasons` (each with its level), `lenses` QA runs (low: conformance, verification-gap, plus domain when the design names a rule; else all five), `inputs`; exit 2 when the story is missing | workflow |
| `eval [S \| --all] [--transcripts DIR] [--gap MIN]` | Claude Code subagent transcripts under `<CLAUDE_CONFIG_DIR or ~/.claude>/projects/<central path with non-alphanumerics as ->/*/subagents/`; `.baton/reads.jsonl`; `-risk.json`; `## Findings by lens` in `-triage.md` | nothing; per story: span, agent and waiting minutes, per agent runs, minutes, tokens in and out, reads and re-reads, per lens findings and unique findings; exit 1 when no transcript names the story, 2 with neither a story nor `--all` | workflow |
| `trace <F> [--story S] [--open]` | the feature note, its stories (live or under `docs/archive/<F>/`), their design, QA, security, confidence and change-note artefacts, `docs/status.md`, `docs/metrics.md`, `profile/domain.md`, `profile/sensors/README.md`, `docs/architecture/workspace.dsl` and `CHANGELOG.md`, the provenance footers (trace.md) | `docs/trace/<F>.html`, one self-contained page; `--json` prints trace.json (schema `trace.json`) instead; exit 2 when the feature has no note and no stories, or `--story` is not one of its stories; 1 when the JSON fails the schema | W1 |
| `tag <S\|F>` | the central repo's git state | an annotated tag `<S>` or `<F>` on the default branch (`origin/HEAD`, else main or master), message `<id>: <title>`; exit 2 off the default branch, on an existing tag or a malformed id (versioning.md section 2) | W1 |
| `stories [--feature F]` | `docs/stories/`, `docs/archive/*/stories/`, and every `story/<F>-<S>` branch (local, then `origin/`) through git | nothing; one line per story: id, feature, State, where (`here`, `archive` or the branch), title | W1 |
| `board [--feature F] [--story S] [--fetch]` | the stories as `stories` finds them; in the central repo and every repo of `profile/project.md`'s table, the branches `story/<F>-<S>` and `feature/<F>-<S>`, local and `origin/`, against the default branch (`origin/HEAD`, else main or master); the tags; `docs/design/<F>/<S>-context.json` and `docs/context/understanding/status.json` for gate 0 | nothing (`--fetch` runs `git fetch --prune origin` in each repo); one line per story: State, gate 0 (`-`, ok, not checked, blocked, stale, refused), central branch (none, empty, not pushed, n unpushed, pushed, merged), code branches, the last commit's age, next move; `--story` one line per branch; merged = the default branch holds the tip and a `<S>:` commit; exit 2 for an unknown `--story` | core |
| `build <S> [--done STEP] [--answer approve\|changes\|block --by TL\|SE\|PO --note N] [--from STEP] [--status] [--security-check]` | the story, its design note, the reports under `docs/qa/<F>/`, `profile/project.md` (`track.auto-pass.confidence`, `jira.labels.extra`, the repo table), each repo's `feature/<F>-<S>` head; runs `context check`, `deps`, `confidence`, `evidence` and `trace` itself | `docs/qa/<F>/<S>-build.json` (the step ledger); the story's `## Design review` and State at gate 2 (through the same check as the state-gate hook); prints the next action (agent, skill, gate, do, done; `--json` as JSON); exit 2 on a stop or a refused `--done`; `--security-check` exit 2 when the security report is missing, BLOCKED or stale, or confidence.json is missing (agent-enhancements.md section 3) | core |
| `agents check [--root P]` | `agents/*.md`, `skills/*/SKILL.md`, `docs/roles.md`, `hooks/`, `contracts/models-and-activation.md` | nothing; exit 1 with one line per problem (agent-enhancements.md section 13) | core |
| `models [S] [--check]` | `profile/models.yaml` (framework defaults when absent; schema `models.json`), the story's Track, test report, `docs/status.md`, `-diff-shape.json` | nothing; the model per role for the story with escalations applied, and the implementer / reviewer pairing; exit 2 when a reviewer role is weaker than what it reviews on any track, or the story is missing | W1 |
| `context ingest [--from P] \| build \| score \| brief <area\|system> \| understand \| questions \| answer <area\|landscape\|flow:N> <Q\|C><n> "<words>" --by PO\|TL \| check <S\|F> [--track T] [--no-write] \| gaps [--layer L] \| trend` | ingest: the documents named by `--from` or `doc-sources` (Confluence HTML export, XML, Markdown, text, CSV, JSON, docx, pptx, xlsx; PDF with `baton[pdf]`); the rest: every repo's sources and tests, `profile/{project,domain,context,stack-detected,dependencies}.*`, `profile/branch-points.yaml`, `docs/wiki/`, `docs/data-profile/`, `docs/features/`, the stories | ingest: `docs/context/sources/<slug>.md`, `docs/context/sources/index.json`; build: `profile/branch-points.yaml`, `profile/domain-drafts.md`; score: `docs/context/context-map.json` + `.md`, `docs/context/modules/<repo>--<module>.md`; check: `docs/design/<F>/<S>-context.md` + `.json`, the story's `## Open questions` (`[context]` lines only), the map's `trend`; check of a feature: `docs/design/<F>/<F>-context.md` + `.json`; understand and check: `docs/context/understanding/status.json` + `.md` + `asked.json`, `docs/context/questions.md`; questions: the same; answer: the line under the question or contradiction in its note, then as understand; brief, gaps and trend write nothing. check exits 2 on a blocking gap, and for a feature when an area it changes is not understood (context-map.md section 10); score, check and gaps exit 2 before the first build (context-map.md) | W1/W2 |
| `install [--from PATH] [--check] [--force] [--python CMD]` | the framework checkout: `--from`, else `BATON_FRAMEWORK`, else the checkout this runs from (a pipx copy has none); `--central` is the target | `.claude/{agents,skills,hooks,sensors,tools/baton}`, `.claude/baton-install.json`; adds `CLAUDE.md`, `profile/*` when missing, baton hooks in `.claude/settings.json`, `graph` in `.mcp.json`, `.gitignore` / `.gitattributes` lines; exit 1 on a conflict (a file edited since the last install) or, with `--check`, on any change; exit 2 when not run from a checkout | workflow |
| `deps [story-id]` | every story under `docs/stories/` | nothing; with an id, exit 0 when it can start, 2 with what it waits for; with no id, lists unfinished stories, dependencies first; exit 2 on a broken list | core |

Rules: a subcommand never calls a network service except `profile` (the named test env) and `wiki --prose` (headless `claude -p`); `diagram` never calls a model or the network; every write is to a path listed above; every subcommand has fixture tests under `tools/baton/tests/<W>/`.
